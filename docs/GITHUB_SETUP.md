# GitHub setup

Suggested repository name:

`symphonium-disc-maker`

Intended URL:

`https://github.com/rharriszzz/symphonium-disc-maker`

From the unpacked directory:

```bash
git init
git add .
git commit -m "Initial Symphonium disc generator"
git branch -M main
git remote add origin git@github.com:rharriszzz/symphonium-disc-maker.git
git push -u origin main
```

Create the empty repository on GitHub first, without adding a README or license,
because this starter archive already contains both.
